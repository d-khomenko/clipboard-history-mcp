## How additions happen

This file is updated manually by the maintainer when a new pledge clears its
first billing cycle. If your name is missing after that, ping `@dmytro` in
Discord or open an issue with the `supporters` label.

Tier benefits + sign-up info: [Patreon page](https://www.patreon.com/c/DmytroKhomenko).
Sponsorship is gratitude — it does **not** grant priority issue triage or
support SLA. See the project [README](./README.md#sponsor) for the full
sponsorship policy.
